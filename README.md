Choose your opponent from the full-screen match setup before making a move. The choice stays locked until the game ends or you select **New game**, at which point the setup screen returns.

## Opponents

- **Novice** searches one move layer deep and occasionally chooses a less accurate move. It is intended for beginners and relaxed games.
- **Expert** searches three layers deep and consistently plays its strongest available move for a tougher challenge.

After a completed match, you can review the game before choosing the next opponent.
